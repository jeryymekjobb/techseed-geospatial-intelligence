# Satellitdata om branden i Västmanland 2014

Arkivdatum: 2026-10-01 (Europe/Stockholm).

Arkivet innehåller chattens fråga och svar med instruktioner och källänkar i `chatt.md`. Inga satellitbilder eller satellitdataprodukter har laddats ner. Länkarna avser källor kontrollerade i samtalet 2026-09-30.

Kontrollera arkivet i terminalen med båda nedladdade filerna i samma katalog:

```bash
sha256sum -c satellitdata-vastmanland-2014-2026-10-01.tar.gz.sha256
```

Förväntat resultat: arkivets filnamn följt av `OK`.

Packa upp:

```bash
tar -xzf satellitdata-vastmanland-2014-2026-10-01.tar.gz
```
